# 4Geeks.com
# README — Antes de editar `online-cv.yml`

Ten preparados estos datos/archivos. Si te falta algo, te trabarás más adelante.

## Identidad y contacto
- [ ] Nombre y apellido exactamente como quieres que aparezcan  
- [ ] Un **párrafo de resumen profesional** (120–160 palabras)  
- [ ] **Foto de perfil** (cuadrada, ≤ 1 MB)  
  - Opción A: **URL pública**  
  - Opción B: archivo en `/static/profile-images/` (ej.: `maria-garcia.jpg`)  
- [ ] Email, teléfono (con prefijo), web (**https://**), LinkedIn (usuario), **GitHub (usuario exacto)**

## Idiomas e intereses
- [ ] Lista de **idiomas** con nivel (**Native** o **Professional**)  
- [ ] **3 hobbies/intereses** (concisos; ej.: *Climbing*, *Cooking*)

## Formación
- [ ] Para cada título: **grado**, **universidad**, **rango de fechas** (ej.: `2019 - 2023`), **logo** (URL opcional)  
- [ ] **2–4 bullets** de logros/énfasis por cada estudio

## Experiencia
- [ ] Para cada empleo/voluntariado: **rol**, **empresa**, **ciudad/país** (opcional), **rango de fechas**  
- [ ] **3–5 bullets de impacto** (métrica + acción + resultado)

## Proyectos
- [ ] **3–5 proyectos**: título, **enlace**, **1 tagline** breve, logo (URL opcional)

## Habilidades
- [ ] **6–10 tecnologías** con nivel en **string con porcentaje** (ej.: `"80%"`)

---

### Notas rápidas de formato YAML
- **Indentación:** 2 espacios (no tabs)  
- **Bloques largos:** usa `|` (p. ej., en `summary` o `details`)  
- **URLs:** siempre con `https://`  
- **`skills.level`:** usar comillas (ej.: `"85%"`)
